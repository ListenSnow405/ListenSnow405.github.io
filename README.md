# ListenSnow405 的博客

这是 [https://listensnow405.github.io](https://listensnow405.github.io) 的源代码仓库，使用 GitHub Pages、Jekyll 和 Minima 主题构建。

## 修改基础信息

站点名称、作者、简介、语言和网址统一配置在 `_config.yml` 中。

## 发布文章

1. 复制 `_drafts/post-template.md`。
2. 将副本放入 `_posts` 目录。
3. 文件名使用 `YYYY-MM-DD-英文短标题.md` 格式，例如 `2026-09-01-my-first-note.md`。
4. 修改文章头部的标题、日期、分类和标签，然后编写正文。
5. 提交并推送到 `main` 分支。

GitHub Pages 构建完成后，文章会自动上线。

## 站点结构

- `_config.yml`：全站基础配置
- `_posts/`：已发布文章
- `_drafts/`：文章草稿和模板
- `index.md`：首页
- `about.md`：关于页面
- `404.html`：未找到页面
