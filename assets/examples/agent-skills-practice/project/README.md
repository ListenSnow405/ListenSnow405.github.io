# 课程资料管理练习项目

六条 CSV 记录与需求草案均为教学模拟。Python 3.10+，仅使用标准库；页面使用原生 HTML、CSS、JavaScript，不加载外部资源。程序不安装 Skill、不调用模型。

解压练习包，终端进入本目录后执行：

```bash
python --version
python prepare.py --output output/run-01
python -m http.server 8766 --bind 127.0.0.1 --directory output/run-01
```

打开 `http://127.0.0.1:8766/`。其他系统可用 `python3` 替换 `python`；换端口时同步修改浏览器地址；结束按 Ctrl+C。HTTP 服务只展示输出目录，不展示完整项目。

基线约定：单课程、单分类、多标签；关键词以不区分大小写的子串方式匹配标题、课程和标签，与分类取交集；空日期为未知；报告始终统计完整清单。需求讨论可确认或调整这些约定，调整后需同步预期结果。

预期：完整清单 6 条；分类“讲义 3、示例代码 2、练习 1”；MAT-05、MAT-06 日期为空；关键词“文件”匹配 MAT-01、MAT-02，叠加分类“讲义”只剩 MAT-01；SQL 匹配 MAT-04、MAT-05；清除筛选恢复六条。

`output/run-01/` 包含页面、脚本、样式、统计 JSON/CSV 和打印用 HTML 报告。程序拒绝覆盖已有目录，重复生成改用 `run-02` 等新名称。生成失败后若有部分目录，也应检查错误并使用新名称，不把部分输出当作成功。

修改源文件后重新生成，旧产物不会自动更新。练习只在本解压目录开展，不在博客仓库中执行重置、清理或批量删除。原始 CSV 保留；网页不提供原始资料下载、登录、数据库、CSV 导入界面或在线发布。
