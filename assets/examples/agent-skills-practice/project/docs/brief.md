# 课程资料管理需求草案

本文件、课程名称与 CSV 记录均为教学模拟，不对应真实课程资料。

个人学习者希望快速查找课程资料，并整理一份报告。当前只有六条 CSV 清单记录，没有账号、数据库、云端存储或原始 PDF 文件。CSV 的标题、课程、分类、标签和日期就是全部已提供的信息。

本次已限定为本机清单浏览与完整清单统计；保留 CSV，产物保存到新目录。模板基线已经实现组合筛选，但以下业务决定仍需练习者通过需求讨论确认，不能仅凭实现反推用户需求：

- 一条资料可以属于几个课程，分类与课程有什么区别？
- 一条资料允许几个分类，标签如何表示多个值？
- 关键词匹配哪些字段，分类与关键词同时使用时是什么关系？
- 两条没有更新日期的记录应该如何展示？
- 报告统计完整输入还是当前筛选结果？

基线采用的教学约定见代码和项目 README；读者也可选择其他决定，但应同步更新契约和预期结果，不能把另一种需求直接评价为代码错误。没有提供的资料内容、文件大小和下载链接应保留为未知。
