# 独立参考材料

教学模拟参考，供练习后核对。本文件不放入模型练习目录或 ZIP；不是原生 Skill 执行结果。

## 需求与术语参考

本例约定单课程、单分类、多标签；关键词匹配标题、课程、标签，忽略大小写，与分类取交集。空日期未提供，报告统计完整输入。没有提供资料正文、大小和下载链接。

资料：由唯一 ID 标识的清单记录。课程：资料所属的教学科目。分类：讲义、示例代码或练习等资料形式。标签：用于检索的主题词，可有多个。未提供更新日期：来源没有给出日期，不等于日期为零，也不等于本次运行日期。

GLOSSARY.md 应保存这些业务含义，不罗列函数和 CSS 选择器。只为有真实长期取舍的决定建立 ADR；六条模拟记录本身不要求架构升级。
