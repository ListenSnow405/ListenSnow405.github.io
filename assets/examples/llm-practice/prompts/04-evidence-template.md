## 主张与证据

每行保留一条能够单独判断的主张；一个来源可支持多行，一行也可引用多个来源。转述与原文短引分开标记。

| 主张编号 | 具体主张与适用范围 | 来源及支持片段 | 状态与理由 | 对结论的影响、下一步 |
| --- | --- | --- | --- | --- |
| [填写] | | | | |

状态可写：资料支持、资料明确否定、版本差异、同范围冲突、当前材料未说明、推断、未读取。它们描述证据；满足、不满足、资料不足描述需求判定，不能混用。

## 引用检查

- 存在：编号、URL、文件及定位是否真实可查？哪些读取失败？
- 支持：片段是否支持该句的对象、版本、数值、条件和强度？
- 覆盖：每个关键结论及其必要前提是否都有依据？
- 冲突：是否保留相反材料，是否存在明确更正或取代依据？
- 执行：本次实际完成的是资料核验、文件保存还是运行测试？
