# 人为故障产物

这组三文件由作者手动加入错误，用于第五篇局部修订练习，不是模型实际生成或失败的记录。复制整个目录到独立练习项目中的 `faulty-v1`；不要直接改博客原件。

按顺序执行 `python validate_output.py faulty-v1`。检查器遇到第一个错误即退出；修正后再运行，继续检查下一项。

1. JSON 最后一条应为 `RUN-03`，被改成了重复的 `RUN-02`；其余字段仍对应 sim-03。
2. TSV 的 `RUN-02` 本应为空值，被改成 `0`，仍标记为 `missing`。
3. Markdown 的 `BT-FILES` 本应保留冲突，被写成 `8 files / known`。

先定位标识，再核对来源，只修改相关记录；三格式同时重写容易掩盖哪个错误已经修复。也可以修正 JSON 后，用生成器写入新目录，保留此目录作为旧版本，但记录中应说明哪些文件重新生成。独立参考答案在 `expected/05-output/`。
