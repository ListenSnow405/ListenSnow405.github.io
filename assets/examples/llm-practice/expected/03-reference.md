- D1 版本 1 是有效需求：同一工具适用于 Windows 11 与 Ubuntu 24.04；UTF-8 纯文本；同一任务 6 个文件、每个不超过 2 MB，不拆分；CSV 的 run_id、status、elapsed_ms 列，毫秒，缺失留空；不联网、不修改输入。
- U1 界面是偏好，U2 许可证缺失记待确认，不直接淘汰。
- S1—S3 版本与日期来自各自 L1；均不能写成当前最新版或真实产品能力。
- F1 与 M1 文件已提供；写作侧已核对，但接收方仍需复核。C1 尚未生成、保存或由读者验收；报告路径只是计划。
- 本轮只生成文本，不安装、不联网、不执行文件写入；读者手动保存另行记录。

F1 的唯一标识集合是 LB、BT、RS 各自的 R1—R6、U1、U2，共 24 个。R/U 在事实表中仅映射字段；事实不提前写为适用性。M1 必要条件共 6×3=18 项，U1、U2 不加入该计数。

## 项目规则与验证范围

`AGENTS.md.txt` 是教学模板。显式读取不等于自动发现验证，文件存在不等于模型已经载入，规则文本不赋予工具权限。Codex 的可选自动加载分支由读者在独立项目中开展；记录当前目录、可确认来源与无法确认项，不预填通过。

写作侧核对资料同步、教学表格、版本依赖、模板与正文一致性、链接及 Jekyll 构建。未开展跨模型独立恢复实验、读者账户记忆设置验证、Codex 自动加载对照、真实工具安装或 API 压缩调用。
