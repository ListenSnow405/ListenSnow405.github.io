# 第九篇程序验证

日期 2026-10-05；Windows，Python 3.11.9。实际使用独立临时目录复制项目、日志和参考，运行标准库评分器；没有模型、API、网络、真实工具故障或在线预算阻断。

22 项验收通过，原始结果见 snapshots/09-evaluation-validation/program-validation.json：

- 36 个任务判定；首轮与最终通过为 6/6、10/10、10/12；调用为 10、10、12，正确阻断各 2。
- 三组教学 token 总估算；含缓存读取、写入的独立算例 0.00515 DEMO；无效缓存计数拒绝。
- bool/integer、重复 JSON 键、重复记录、冲突双方定位、人工验收 pending。
- 用量 null 传播，工具费用未知时保留 token 估算；零正确任务无单位成本。
- 缺少与重复任务拒绝统计；C06 调用模型、W0 超次数与超时间均记过程错误。
- 实际命令生成 report.json；相同输出目录拒绝且既有文件摘要不变；日志与参考摘要不变。

最初 Windows 子进程错误文本以默认编码输出，验证脚本按 UTF-8 读取时出现解码异常；脚本已明确 PYTHONIOENCODING=utf-8，随后完整重跑通过。该修正仅影响验收脚本收集输出，没有改动候选、事实或教学用量。

teaching-runs.json 为人为夹具，由 make_replay.py 构造，不是模型响应或实测时钟。recalculated-report.json 是程序实际重算输出，包含逐任务自动判定与 human_review=pending。程序只根据日志计价与检查明显过程限制，不运行 W1、不产生模型修订反馈、不保证日志真实性，也不代替原文语义复核。

其他 Python 版本、Bash 原生执行、真实模型或模型评审、账单与多轮在线工作流尚未验证。页面与构建验证属于博客集成，和以上程序验收分别报告。
