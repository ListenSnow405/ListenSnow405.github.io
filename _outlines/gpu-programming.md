# GPU 编程系列学习大纲

状态：规划稿；[导读已写入文章目录](../_posts/2026-09-27-gpu-computing-roadmap.md)，其余专题待写。

## 目标读者与内容边界

本系列面向能阅读 C++ 变量、循环和数组，但尚无 GPU 并行编程经验的读者。指针、编译流程等知识在首次需要时补充，不要求读者预先掌握 CUDA。学习目标是能够独立实现正确的 GPU 算子，定位性能瓶颈，提出改进方案，并通过可复现的测试判断改进是否有效。

主线是通用 GPU 计算：以 CUDA C++ 编写和分析完整案例，再比较 HIP、SYCL、Triton 等路线。图形渲染与着色器编程属于相关但不同的学习方向，暂不纳入本系列。CUDA 案例需要支持相应工具链的 NVIDIA GPU；其他硬件路线在跨平台专题中讨论，撰写具体文章前再核对可用设备与软件环境。

## 初学者写作与配图原则

面向首次接触 GPU 编程的读者，每篇先交代输入、输出、必要的 C++ 或并行计算基础，再引入新术语。第一次使用主机、设备、核函数、线程块等概念时给出直观定义，并说明它们在案例中的具体对应物；不以术语表代替正文解释。

在任务拆分、线程映射、内存流向或性能对比等容易产生空间或流程误解的位置，使用简洁图解。图片需要准确的替代文本和可读的说明，关键结论仍写在正文；图中文字保持少量且足够大，便于窄屏阅读。配图服务于理解，不为了数量而添加装饰。

## 贯穿案例与学习方法

系列以“图像批处理”为持续演进的练习项目：从一维向量运算建立最小闭环，再处理二维图像、卷积、直方图和批量流水线。矩阵乘法作为计算密集型的独立对照案例，多 GPU 专题则将独立批次分配到不同设备。

每个案例保留 CPU 参考结果、代表性输入和性能基线。专题文章说明初始状态、必要概念、操作目的、预期结果与验证方法；每次性能改动先检查正确性，再记录端到端耗时及相关指标。替代实现与连续步骤应明确区分，避免读者将所有代码不加选择地依次执行。

## 发布顺序与资料

先完成导读和三篇入门文章，形成可运行、可验证的最小闭环；再发布正确性与性能专题；最后展开应用集成、多 GPU 和跨平台内容。篇目可在写作前根据实际案例负担调整，但每个知识点应有明确的主要讲解位置，避免多篇重复。
